🔧 Cara Pakai di Roblox Studio

1. Buka Roblox Studio → klik Lighting di Explorer

2. Insert → Sky

3. Upload 6 image ke Roblox (Asset Manager → Images → Bulk Import)

4. Set properties:

SkyboxFt → hazmi_skybox_Ft.png
SkyboxBk → hazmi_skybox_Bk.png
SkyboxLf → hazmi_skybox_Lf.png
SkyboxRt → hazmi_skybox_Rt.png
SkyboxUp → hazmi_skybox_Up.png
SkyboxDn → hazmi_skybox_Dn.png

5. Playtest! 🎉
